# Регрессионная часть: детектор с ограничением стороны 2000 px

Тот же вариант, что `../ocr_grouped_max2000_tune_20260923` (см. NOTE.md там):
PP-OCRv5_server_det с `text_det_limit_type=max`, `text_det_limit_side_len=2000`,
объединение фрагментов строки, повторное распознавание ×4 моделью
cyrillic_PP-OCRv5_mobile_rec, CPU, отдельное окружение
`/tmp/rus-vines-paddle-ocr`. В ранжирование допускаются только объединённые
строки с уверенностью ≥ 0.85; кандидаты, геометрия и исходный OCR
заморожены из `final3_test.json`.

Виды запроса выбраны как в сервисе (`prepare_views.py`: raw против detect
по косинусу, `pick_view`), сохранены без потерь в `crops/` (в репозиторий
не кладутся — производные полевых фотографий). Один запуск, полный проход
203 кадров. Замер после фиксации варианта на tune; регрессионная часть —
development-набор, не независимая приёмка.
